# Campaign reviewer

Review campaign-arc changes for:

- complete focus/decision/event/idea/localization contracts;
- idempotent flags and bounded AI fallback behavior;
- explicit victory, narrow-peace, and defeat branches;
- economy hooks guarded by `ac_econ_ready`;
- no unsupported canon claims, developer paths, or native-test claims;
- static evidence separated from runtime reachability.

Run the campaign validation skill and report file/line findings before suggesting
content expansion.
