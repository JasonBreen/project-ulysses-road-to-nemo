# Legitimate-release foundations

This component implements the seven inherited landless histories **AWW, REC,
REL, SBK, SER, SHI and TER**. RAT remains an active start owned by WorldStarts;
PLH/state 171 is protected and receives no inferred setup. It adds no activation
war, border, core, population, country tag, historical replay or automatic
combat formation. Source base: the composed `224c 9ccb` review checkpoint.

The event inputs in `event_inputs.json` record inherited mod content, not
official chronology. Capital selection, maintenance models, technical recipes,
transport stocks, projects and office presentations are provisional gameplay
calibration. No new canonical city, aircraft, deposit or officeholder is asserted.

## Lifecycle and saves

`author.py` owns eight narrowly wrapped existing events and the release
on-actions/effects. Existing event IDs, choices, force fractions, OOBs, territorial
settlements, core differences, leaders and native political outcomes are retained.
Unrelated events retain their parsed source; `source_contract.py` compares the
protected native operations and rejects mutated transfers or settlements.

On the first initialization the framework snapshots which countries already
exist. An existing or exiled government is adopted without stocks, factories,
templates, armies, portraits/leader replacement or historical-event replay.
Future legitimate free/puppet releases and the existing authored entry routes
can register once. The physical, transport, maintenance, event-family and
financial receipts remain separate. Global receipts survive annexation and
prevent a second transfer, birth army, transport reserve or leader promotion.

AWW retains its original quarter-BLK army/stock/fuel transfer and nine additional
formations. The delayed army callback needs its live seven-day entry window;
annexation, capitulation or expiration blocks stale callbacks. The three South
Belkan collapse events share one receipt for their unchanged 25%/25%/15% options.
Recta's original birth army remains ten formations; the two-state treaty route
does not replay that army. Stale option effects are guarded as well as triggers.

The public `ac_econ_adopt_release_account` and canonical monthly owner initialize
a genuinely new account with **zero cash/debt seed**, preserve valid accounts,
and lock incomplete or mismatched identities for review without erasing their
stocks or obligations. State output remains in the P 1 controller/accounting
owner; release callers never write GDP, treasury, debt, arrears or escrow.
Ordinary opening balances and the private legacy v 1 contract remain unchanged.
This does not force a pre-framework save into full macroeconomics.

the airport nearest the area-weighted centroid of the largest controlled owned

emitted. All source geometry, state identities, history quantities and state 171
are hash-protected; no map/history file is rewritten by this component.

## Maintenance and development

Only a genuinely new eligible release receives **2 trains,12 trucks and 6
convoys**, once. Existing transferred fuel/stocks are preserved. Maintenance
registration adds four- and two-battalion infantry templates without deploying
any personnel. The smaller template gives tiny footprints such as treaty Recta
a recruitable option without a manpower/core/law gift. Actual deployment still
needs real manpower and equipment.

Ten replacement roles cover rifles, support, artillery, trucks, trains,
fighters, CAS, convoys, escorts and submarines. A line costs 15 PP, requests one
currently available factory/yard and requires the current selected recipe's
material balance. The adapter counts its previously reserved lines and
rechecks eligibility in completion. Technical research/designs precede the
typed consumer; independent negative mutations reject the reverse order.
Nothing is automatically produced or placed on a mission at registration.

An alternative 5 PP certification unlocks a recipe without opening another line,
so a government whose industry is fully assigned can rotate production manually.
The source does not claim automatic AI rotation, guaranteed imports, complete
replacement coverage for every dynamically transferred mixed formation, or
unlimited fuel. Regular Production edits remain under player control.

One CIV and one MIL project per country each cost 100 PP plus **0.02b in full
mode or 20 FU in legacy mode**, take 90 days, and require a controlled core capital
with a free slot. These are separate calibrated prices, not a currency
conversion. Fiscal-disabled campaigns retain the PP/time/territory costs.
Payment uses the guarded public `ac_econ_try_fund_release_project`; no callback
subtracts private balances. Failed payments give no project. Completion
rechecks the paid target, core, ownership, control, capitulation and slots.
Cancellation/interruption is nonrefundable and has a 30-day cooldown. Old queued
callbacks cannot finish a subsequently restarted project early.

The optional 90-day network project costs 50 PP plus the same public fiscal fee.
Eleven exact captured network cases contain 49 candidate missing-edge records
across alternatives. Routes use actual adjacent owned land provinces; existing
rail edges are excluded at capture and a live `has_railway_connection` guard
also skips subsequently constructed/upgraded edges. No rail crosses water and
no new coast, VP, hub or port is invented. Disconnected components use existing
receiving ports and real convoys. Unknown footprints use normal construction.
State-controller hooks, capitulation/annexation hooks, monthly supervision and
completion checks handle interruption; transient province changes between
observations are not claimed as fully native-tested interruption coverage.

Scoped AI plans prioritize affordable infantry replacement, industry and
support research, retain a modest recruitment preference, and provide optional
territorial templates with zero forced-upgrade priority. They do not change
factions, wars or existing formations. Natural AI pacing remains untested.

## Preserved liabilities

`worksheet.json` contains 14 footprint cases and 56 BBA/MTG projections, with ten
optional role recipes per projection. It derives personnel, resource needs,
conservative core capacity, consumer goods, conditional imports and reference
replacement rates from actual state/law/primary definitions. Four DLC choices
do not establish every inherited NSB/LaR mission capability.

AWW's nine inherited formations alone require 68,400 personnel, before any BLK
fraction or 10% replacement reserve. It has no core population and retains
`disarmed_nation`; **the zero core-pool bound is not a claim of zero possible
non-core or future weekly recruitment**. Its original optionA keeps the existing
500-weekly-manpower idea; optionB does not gain it. Warfront OOB locations outside
its initial footprint are preserved inherited references, not newly accepted
owned deployment sites. Non-core capacity, source geography and that force debt
are explicit release gates. No new conscription law, core, population, instant
personnel or autarkic resource solution is added.

Treaty Recta has a conservative 3,700-person core pool and no core MIL at entry;
it receives no ten-formation birth grant. The two-battalion template and paid
development route remain optional future choices. South Belkan armistice has
no added cores, in contrast to defeat. Terentio has no conservative spare trade
CIV at its inherited law. Conditional import rows are not authored guaranteed
contracts. The registry therefore keeps universal sustainable-release acceptance
**false**. The 61-start packet's UST manpower debt and BLK 309 sealed-component
exception remain unchanged.

## Government representations and artwork

Council/Gross/Clarkson roles remain unchanged. New primary regimes explicitly
use an eligible authored role; any other existing authored ruling leader is
respected. Only a genuinely new government without an eligible authored ruler
gets `AWW_ac_release_government_office`, `REC_ac_release_government_office` or
`SHI_ac_release_government_office`. The fallback uses the actual current ideology
taxonomy and verified recruit/add-role/promote APIs. Existing office identities
for REL/SBK/SER/TER can serve their new regime. Adopted/saved/re-released leaders
are never replaced, and independent receipts prevent duplicate roles.

SHI and DEL inherit the same Clarkson character ID. The adapter never steals or
duplicates a character already associated with another country. SHI keeps the
authored individual when actually available; otherwise its unknown officeholder
uses the office representation. That shared inherited identity still needs
native observation; it is not silently renamed or assigned a biography.

`build_art.py` packages 14 original briefing icon compositions and three office
cards using the existing flags and shared original glyph library. Row sprites
are separate **26×29 RGBA DDS** assets; category sprites are 100×100 and office
cards 156×210. Category and row aliases use distinct tokens and bindings.
`assets.json` records dimensions, frame counts, alpha, source hashes and sprite
bindings. No watermark, new face or invented biography is included. The contact
sheet is an offline packaging artifact, not a game screenshot.

## Reproduction and evidence

Use Python 3.12, Pillow 11.3.0 and numpy 2.2.6. With a read-only 1.19.4.1 reference:

```powershell
python -B tools/release_foundations/intake.py --reference $GameRoot
python -B tools/release_foundations/leaders.py
python -B tools/release_foundations/physical.py --reference $GameRoot
python -B tools/release_foundations/author.py
python -B tools/release_foundations/release_worksheet.py --reference $GameRoot
python -B tools/release_foundations/build_art.py
python -B tools/economy_v 2/build.py
python -B tools/world_foundation/registry.py --output tools/world_foundation/country_registry.json
python -B tools/world_starts/release_inventory.py
python -B tools/release_foundations/run_checks.py --reference $GameRoot
```

Ordinary authoring never recaptures `event_inputs.json`; that input retains the
original event operations. Every generator has a read-only `--check` route.
Registry equality is checked against an explicit regenerated file, not a printed
summary. The runner inspects every subprocess exit code separately.

Evidence tiers remain separate: actual-script Decimal/territory fixtures,
protected-source/geometry/primary checks, DDS packaging and broad offline
regressions are source evidence. Copied-state snapshots are not HOI 4 save
serialization. **Native testing is paused**: release hook ordering, character
ownership/promotion, engine parsing, DLC loading, supply delivery, production
efficiency interpretation, natural AI, GUI rendering and real save/reload remain
unaccepted. No normal installation, profile, save or playset was changed.
