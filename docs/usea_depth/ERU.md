The AI path is Crown absolutism (`ERU_ud_path_prerogative`, weight 60); the other two openers have weight 0, so AI Erusea keeps its 1991 monarchy. Erusea's postwar 'never a forced government swap' rule is unchanged: no postwar focus changes the government.

## Era bands and the December 1999 hand-over

Every opening focus has `available = { ... date < 1999.12.1 NOT = { has_global_flag = ac_ucw_calendar_started } }`. Era-band focuses add the band's date. `ac_ud_eru_weekly` (from `on_weekly_ERU`) fires the five era transitions once, and a late load marks a past era without replaying it.

`ac_ud_eru_carry_over` runs once, after `ac_ucw_country_start` has seeded the Continental War indices. It sets `ERU_ud_war_crown`, `ERU_ud_war_assembly` or `ERU_ud_war_regency` (Crown by default, and after a regency that returned the seals), applies small index changes and fires `ac_ud_eru.40`-`.42`. The war-tree lanes read only those flags or flags set by existing focuses; no war-tree focus has a prerequisite line into the older part of the tree.

## The war still starts

No file in this package writes or clears an `ac_ucw_*` global flag or edits `ac_ucw_country_start`. Every focus or event option that lowers `ac_ucw_grievance` has AI weight 0. `test_eru.py` runs AI Erusea from 1 January 1991 through 2003 in the World harness of `tools/Test-ContinentalWar.py`, with this package applied, and asserts that the grievance never drops below 25 and that the war starts in summer 2003.
