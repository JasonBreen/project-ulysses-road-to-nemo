# Usea Depth: minors B ledger

Generated by `python -B tools/usea_depth/minors_b/build.py`; do not edit by hand. Package contract: [README.md](README.md). Native status: not tested in HOI4. Native acceptance remains under #8.

Package `minors_b` gives Spayca, Calladen, Roca Roja, Rohden, Voslage and Corscae their own national trees, and Shilage a short release tree. They replace the shared 36-focus regional tree for these tags by weight (+45 against +5). Old saves switch through each country's "Adopt" decision, gated on `ac_pol_previous_tree_idle`.

## Source rules

- No official source describes any of these states. Every tree, event, idea, office and decision is **provisional gameplay**. Each state's provinces, resources, buildings, neighbours, ruling party and treaty-council membership are read from the mod's own history files and are **mod provenance**.
- Official dates are used only as calendar gates and as reported news: ACES Chronicle 1996 / 04.20 (Ulysses announced), 1997 / 05.30 (Usea-wide coup), 1998 / 06.19 (Stonehenge completed), 1999 / 07.08 (impact), 2000 / 04.21 (Erusean refugee closure) and the 2003-2005 war rows ([Chronicle](https://acecombat.jp/en/chronicle/details/), as compiled in [USEAN_CONTINENTAL_WAR.md](../USEAN_CONTINENTAL_WAR.md)).
- No new named people: every new government is an unnamed office card with a generated portrait. Chronicle people appear in text only. No Chronicle place is mapped to a state; Stonehenge = state 310 stays the only mapping.
- The "Central Usean Treaty Council" is the mod's `CNEA_member_idea` membership (mod provenance: the history files of the members, and the `CNEA_parliament_decisions_category` label). This package never adds or removes that idea.
- No `transfer_state`, cores, borders, wars, annexations or faction changes. No `ac_ucw_*` flag writes. Nothing reads or writes Erusea's grievance. The AI never takes a political path, so it keeps the 1991 governments.
