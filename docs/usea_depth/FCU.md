# Usea Depth: Central Usea (FCU)

Generated by `tools/usea_depth/fcu/build.py` from `content.py` and `narrative.py`; do not edit by hand.
Package contract: [README](README.md). Native status: not tested in HOI4. Native acceptance remains under #8.

## Source layers

- **Official.** The [ACES Chronicle details page](https://acecombat.jp/en/chronicle/details/), cited as *Chronicle, YYYY / MM.DD*, and the [Super Weapons page](https://acecombat.jp/en/chronicle/weapons/), cited as *Super Weapons, name*. Entries are paraphrased. The only Usea anchors used are 1995 / 12.31, 1996 / 04.20, 1997 / 05.30, 1998 / 06.19, 1999 / 07.08, 2000 / 04.21 and the 2003-2005 war rows.
- **Mod provenance.** The Usean Treaty Organization (UTO), CNEA, FCU's 1991 faction (with SNS as a member, which differs from the Chronicle's neutral San Salvacion), the 1991 western standoff in the bookmark text, and Robert Sinclair's 1991 term (user-approved provisional chronology, recorded in `docs/USEA_INTERFACE_FCU_ADDENDUM.md`).
- **Provisional gameplay.** Everything else: every choice, modifier, cost, index and outcome lane.
- **Alternate history.** The emergency Unified Command directorate and the federal unity government are player-only provisional gameplay. No source shows a Central Usea regime change before ISAF's founding on 22 August 2003. Every focus that reaches a government change has `ai_will_do = { factor = 0 }`, so the AI keeps the 1991 government.
