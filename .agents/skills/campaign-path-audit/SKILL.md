# Campaign path audit

Use `tools/analysis/campaign_path_report.py` to summarize focus and decision
references into campaign events and event idea/flag effects. Compare the report
with the intended phase plan and the native playtest checklist.

Treat unresolved references as defects to investigate, but do not convert a
static reference into a runtime claim. Record any provisional gameplay branch
as provisional rather than official Strangereal history.
