# Southern and Anean story artwork: plan only

[plan.json](plan.json) is generated by [plan.py](plan.py) from the story
metadata. It lists **32 original masters** with exact prompts:

| Host | Story | Portraits | Scenes | Loading | Masters |
| --- | --- | ---: | ---: | ---: | ---: |
| AUR | Kept in Repair (`tools/squadrons/southern`) | 4 | 8 (core slots 1-5, endings 6/7/8) | 1 | 13 |
| LEA | Orders in Two Hands (`tools/squadrons/southern`) | 4 | 8 | 1 | 13 |
| EMM | Open Corridor continuation (`tools/squadrons/anean_epilogue`) | reuses the originals | 3 | none | 3 |
| EVA | Last Serviceable Aircraft continuation (`tools/squadrons/anean_epilogue`) | reuses the originals | 3 | none | 3 |

Prompts use the exact Pacific portrait, scene and loading templates
(`tools/squadrons/pacific_art/plan.json`), so the new masters match the
existing story art: painted-realistic editorial aviation art, navy/cyan
restraint, no text, insignia, flag, identifiable aircraft, landmark,
airborne combat or official character, and no national outcome asserted.

## Status: awaiting generation

Every master is `awaiting generation`. The authoring session had no image
generator, so **no picture was made and none is substituted**. The stories
and epilogues are therefore not admitted: their scripts exist as validated,
pinned offline previews (`preview.json` in each component) and nothing is
written to the mod. `plan.py --check` refuses an admitted host whose masters
are not all reviewed, and refuses an image file present without a reviewed
record.

## Admitting a host

1. In a session with the built-in image generator (or with masters supplied
   by the user), generate each master from its exact `prompt`. Save it at
   `tools/squadrons/southern_art/<file>` and record its raw SHA-256 and a
   visual review in `plan.json` (`status: original master visually
   reviewed`), as the Pacific component did (`pacific_art/intake.py`,
   `review.py`). A rejected output is regenerated, never painted over.
2. Package the masters with the Pacific packaging contracts (portraits
   156x210 full-height contain; scenes 200x160 contain; loading center cover
   to 1920x1080 and 3440:1440) and bind every sprite the compiled scripts name:
   `GFX_ac_sqs_<tag>_scene_<slot>`, `GFX_ac_sqs_cast_<id>`, the category and
   decision icons (`GFX_ac_sqs_category_<tag>`, `ac_sqs_<tag>_read` and its
   pause/resume siblings, reusing the Pacific frames as `pacific/build_art.py`
   does) and `GFX_ac_sqa_<tag>_scene_<slot>`.
3. Add the tag to `ADMITTED` (`southern/story_contract.py` or
   `anean_epilogue/epilogue_contract.py`), run the component's `build.py` to
   write the mod files, then `build.py --check`, `plan.py --check` and the
   runtime tests.

Until step 3, the release plan records the Aurelian and Leasathian stories
as `text_and_script_preview_validated_art_awaiting_generation_unadmitted`.
